Build the BMI Calculator, one clean step at a time

The smallest real PHP project you can ship: a form, a calculation, a result. Follow these eight steps in order — each one adds exactly one new concept.

Formula weight ÷ height²
Files 1 (index.php)
Time ~1–2 hours

Static HTML shell

Write the form first with no PHP logic at all: two inputs (weight, height), a submit button. Just get it rendering in the browser.

form structure, method="POST"

Submit the form to itself

Set the action to the same page so submitting reloads it. Don't calculate anything yet — just inspect what PHP receives.

var_dump($_POST);
$_POST, GET vs POST

Detect the submission

Wrap your logic so it only runs after the form is submitted, not on first page load.

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // calculation goes here
}
request method checking

Validate the input

Check that weight and height aren't empty and are numeric, and that height isn't zero — division by zero will break the calculation.

is_numeric(), input guarding

Do the calculation

Apply the BMI formula. If your form takes height in cm, convert to meters first.

$bmi = $weight / (($height / 100) ** 2);
type casting, math in PHP

Categorize the result

Map the BMI number to a category using if/elseif.

BMI rangeCategory
< 18.5Underweight
18.5 – 24.9Normal
25 – 29.9Overweight
30+Obese
conditional chains

Display the result safely

Echo the BMI and category back to the page, escaping any user-provided output.

echo htmlspecialchars($category);
output escaping · security habit

Polish

Round the BMI to one decimal, re-fill the form with the submitted values, and add a bit of CSS so it feels finished.

round($bmi, 1);
round(), sticky form values, UX
