Grade / Average Calculator

Enter several scores, get back an average and a letter grade. This is your first project that works on a list of numbers instead of just one or two.

arrays
loops

~25–35 min build time

What this project is

A form where someone enters a handful of scores. PHP adds them up, divides by how many there are, and converts that average into a letter grade.

◧

What is this

Instead of one input (like your Sign Checker) or two (Sum Calculator), this form collects a set of scores — think 3 to 6 fields, or one field where someone types comma-separated numbers.

  • Collect all the scores into one PHP array
  • Loop through the array to total them up
  • Divide the total by the count to get the average
  • Map that average to a letter grade (A–F)
✦

Why it matters for a beginner

This is the project where arrays and loops stop being theory and start being the only reasonable way to solve the problem.

  • You can't validate "each score" without looping over them one by one
  • You can't sum a variable number of inputs without a loop
  • The grade lookup reuses your BMI-category pattern — but now feeding it a calculated value, not raw input
  • Real e-learning platforms do this exact calculation for quiz/course grades

How it works — 3 examples

Same three steps every time: sum → average → grade. Only the numbers change.

Build roadmap

Same step-by-step approach as before — build it in this order, test after each step before moving on.

Static form shell

Build the HTML form first, no PHP yet. Use a fixed set of inputs — e.g. 5 fields named scores[] — so every submission sends an array to PHP automatically.

array-named inputs

Submit to self, detect POST

Same pattern as always: method="POST" action="", then check $_SERVER['REQUEST_METHOD'] === 'POST' before touching any logic.

Pull the raw array

Grab everything in one go: $rawScores = $_POST['scores'] ?? []; — at this point it's just an array of strings, some possibly empty.

arrays

Loop + validate each score

Loop over $rawScores with foreach. Skip blanks, reject anything that isn't numeric or falls outside 0–100, and collect the good ones into a fresh $validScores array. This is the same "empty string sneaks past ?? "-style bug you already hit once — watch for it here too.

loops · validation

Guard against zero valid scores

If $validScores ends up empty (everyone left every field blank), stop and show an error — don't divide by zero in the next step.

Sum and average

Loop again (or use array_sum()) to total $validScores, then divide by count($validScores) to get the average.

loops

Map average → letter grade

Reuse the data-driven lookup pattern from your BMI project: an array of thresholds walked in order (90/80/70/60), instead of a chain of if/elseif.

array lookup

Build $resultHtml, escape, polish

Build the whole result — score chips, average, grade badge — as one string in the top PHP block, escape every value with htmlspecialchars(), then echo it once in the body. No mixed PHP/HTML in the markup.
