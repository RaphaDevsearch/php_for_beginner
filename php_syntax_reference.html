PHP Syntax Reference

A working reference for the syntax you'll use over and over — every example pulled from real patterns, most straight from projects already built.

01 / 13

PHP Tags & Embedding in HTML

PHP code lives inside <?php ?> tags. Everything outside those tags is treated as plain HTML and sent to the browser as-is.

basic block + one printed value
<?php
    $name = "Raphael";
?>
<h1>Hello, <?= $name ?></h1>
long echo vs. shorthand echo
<?php echo "This works too"; ?>

// <?= ?> is shorthand for <?php echo ?>
<?= "Shorthand, only for printing one value" ?>
your own pattern: logic on top, one echo below
<?php
    $resultHtml = buildResultHtml($data);
?>
<div class="result-shell">
    <?= $resultHtml ?>
</div>
By the time the browser receives the page, every <?php ?> tag is already gone — the browser only ever sees the HTML that PHP produced, never the PHP code itself.

Variables & Data Types

Every PHP variable starts with $. Types aren't declared upfront — PHP figures them out from the value assigned.

the four basic types
$name = "Raphael";     // string
$age = 24;              // int
$price = 12.99;         // float
$isValid = true;        // bool
type casting — form input is always a string first
$rawInput = "45";             // string, straight from $_POST
$number = (float) $rawInput;   // now a real number, 45.0
typed function parameters & return types
function calculateAverage(array $scores): ?float {
    // array goes in, a float (or null) comes out
}
03 / 13

Operators & Expressions

Comparisons, shorthand conditionals, and the null coalescing operator you already lean on constantly.

comparison — loose vs. strict
$number > 0;      // greater than
$number === 0;    // equal AND same type — use this by default
$number == "0";   // equal, loose — this is where sneaky bugs hide
ternary — shorthand if/else
$word = $isEven ? 'even' : 'odd';

// same as writing:
if ($isEven) { $word = 'even'; } else { $word = 'odd'; }
null coalescing — fallback when a key is missing
$rawScores = $_POST['scores'] ?? [];
// catches "missing" — but NOT an empty string "", watch for that
04 / 13

Strings & Concatenation

Two ways to build a string out of pieces — the dot operator, or interpolating variables directly inside double quotes.

the dot operator
$message = "The number " . $safeNumber . " is " . $sign . ".";
interpolation — variables inside double quotes
$message = "The number $safeNumber is $sign.";
// only works with double quotes " ", not single quotes ' '
building HTML piece by piece with .=
$html = '';
$html .= '<span class="score-chip">' . $score . '</span>';
// .= means "add this onto the end of the string"
05 / 13

Conditionals

Branching logic — kept in the top PHP block, never scattered through markup.

if / elseif / else
if ($number > 0) {
    $sign = 'positive';
} elseif ($number < 0) {
    $sign = 'negative';
} else {
    $sign = 'zero';
}
guard clause — stop early before a risky operation
if (count($validScores) === 0) {
    return null; // stop here — avoids dividing by zero next
}
whitelist check with in_array()
$allowedTypes = ['link', 'text'];

if (!in_array($rawType, $allowedTypes, true)) {
    $type = 'link'; // fall back to a safe default
}
06 / 13

Arrays

One variable holding many values — indexed by number, by a name you choose, or nested inside each other.

indexed array
$scores = [78, 85, 92];
echo $scores[0]; // 78 — indexes start at 0
associative array — threshold lookup pattern
$gradeScale = [
    90 => 'A',
    80 => 'B',
    70 => 'C',
];
multidimensional — the actual shape of scores[]
$_POST = [
    'scores' => [45, 65, 56]
];
echo $_POST['scores'][0]; // 45
07 / 13

Loops

foreach is what you'll reach for almost every time you're working with an array.

foreach — value only
foreach ($scores as $score) {
    echo $score . "<br>";
}
foreach — key and value together
foreach ($gradeScale as $minScore => $grade) {
    if ($average >= $minScore) {
        return $grade; // first match wins
    }
}
for — when you need a counter
for ($i = 0; $i < count($scores); $i++) {
    echo "Score #$i: " . $scores[$i];
}

Functions

One function, one clear job — same rule you've been applying since your very first project.

basic function
function check_sign($number) {
    return $number > 0 ? 'positive' : 'negative';
}
typed parameters and return value
function validateScore(string $rawScore): array {
    // ...
    return ['valid' => true, 'value' => 78.0];
}
default parameter value
function buildQrCodeUrl(string $link, int $size = 300): string {
    // $size is 300 automatically unless the caller passes their own
}
09 / 13

Superglobals

Built-in arrays PHP fills in for you automatically — available in every file, no setup needed.

$_POST — data from a submitted form
$link = $_POST['link'] ?? '';
$_SERVER — info about the current request
$isPost = $_SERVER['REQUEST_METHOD'] === 'POST';
$_GET — data from the URL itself
// page.php?id=5
$id = $_GET['id'] ?? null;
10 / 13

Validation Functions

Never trust input as-is — check it before doing anything with it.

is_numeric() — is this a real number?
if (!is_numeric($rawScore)) {
    $errors[] = 'Not a valid number.';
}
filter_var() — is this a real URL?
if (filter_var($rawLink, FILTER_VALIDATE_URL) === false) {
    $errors[] = 'Not a valid link.';
}
range check — a manual rule, no built-in needed
if ($number < 0 || $number > 100) {
    $errors[] = 'Must be between 0 and 100.';
}
11 / 13

Escaping Output

Any time user input gets printed back onto the page, escape it first — no exceptions.

basic usage
echo htmlspecialchars($_POST['name']);
escaping before building a bigger string
$safeNumber = htmlspecialchars($rawNumber);
$html = "The number is $safeNumber.";
what it actually prevents
// input: <script>alert('hi')</script>
// without htmlspecialchars(): runs as real code in the browser
// with htmlspecialchars(): displays as harmless visible text
This rule has no exceptions — even values you're sure are "just numbers" get escaped, so the habit never has to be decided case-by-case.
12 / 13

PHP + JavaScript

PHP finishes running before the browser sees anything. To hand PHP data to JavaScript, it has to be printed into the page as the page is built.

passing one value with json_encode()
<script>
    const average = <?= json_encode($average) ?>;
</script>
passing a whole array
<script>
    const scores = <?= json_encode($validScores) ?>;
</script>
what does NOT work — JS can't call PHP directly
// This does nothing — validateScore() is a PHP function.
// By the time this button exists in the browser, PHP is done running.
<button onclick="validateScore()">Check</button>
Calling PHP again after the page has loaded — without a full reload — needs a separate technique (AJAX/fetch). Not needed yet for anything built so far, but useful to know it's the next layer up.
13 / 13

Include & Require

Splitting one growing file into several reusable pieces — the natural next step once functions like validateScores() start getting written more than once.

include — pulls another file's code in
include 'functions.php';
require — same idea, but stops the page if the file is missing
require 'functions.php'; // fatal error if the file isn't found
sharing one function across multiple project files
// functions.php
function safe($value) { return htmlspecialchars($value); }

// grad_calculator.php
require 'functions.php';
echo safe($name);
